# 🗺️ Дорожная карта развития PlanMeBot

## 1. Фундамент и Инфраструктура (Refactoring)

*Перед добавлением новых функций нужно подготовить "почву".*

* **Миграция на SQLAlchemy:** Переход с прямого SQL на ORM для удобного управления связями (особенно для групповых задач).
* **Логирование (Logging):** Внедрение `structlog` или стандартного `logging` для отслеживания ошибок и действий пользователей.
* **Мультиязычность (i18n):** * Поддержка **RU, EN, IT**.
* Использование библиотеки `aiogram-i18n` или хранение строк в `.json` / `.yaml` файлах.
* Язык пользователя выбор через команду `/language`.



## 2. Улучшение Пользовательского Интерфейса (UX/UI)

*Сделаем взаимодействие с ботом удобнее.*

* **Inline-календарь:** Замена ручного ввода даты на интерактивный календарь (библиотека `aiogram3-calendar`).
* **Система уведомлений:**
* Добавление фонового планировщика (`APScheduler`).
* Настройка напоминаний по календарю.
* Возможность кастомизации времени напоминания для каждой задачи.



## 3.**Внешние API:**
* Синхронизация с **Google Calendar** (OAuth2).
* Экспорт/импорт задач в **Notion**.



## 4. Интеграция Искусственного Интеллекта (Gemini AI)

*Самая инновационная часть проекта.*

* **Ежедневный гороскоп:** - кнопка, запрос даты рождения, определние знака зодиака
* Генерация предсказаний на основе знака зодиака пользователя.
* Поддержка стилей: выбор для юзера *Юмористический, Мотивирующий, Строгий*.
* Генерация сразу на языке пользователя (RU/EN/IT).


* **Умные напоминания (Smart Reminders):**
* Обработка текста задачи через Gemini для создания "человечного" и вдохновляющего пуш-уведомления.


* **AI-Саммари дня:**
* Кнопка "Итоги дня".
* Анализ выполненных и просроченных задач.
* Персональные советы по продуктивности от AI.

2. Создать модуль `horoscope.py`.
3. Реализовать "Умные уведомления".

1. Реализовать интеграцию с Google/Notion.
