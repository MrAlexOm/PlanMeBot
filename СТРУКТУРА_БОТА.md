# 🤖 PlanMeBOT - Структура и Архитектура

## 📋 Общее описание

PlanMeBOT - это интеллектуальный Telegram-бот для управления задачами с интеграцией ИИ, погодными данными и гороскопами.

### 🎯 Основные функции:
- 📝 Создание задач через естественный язык (NLP)
- 📅 Умное планирование с календарем
- ⏰ Напоминания с учетом часовых поясов
- 🌤️ Погодные уведомления
- 🔮 Персонализированные гороскопы
- 🌍 Мультиязычность (RU/EN/IT)

## 🌍 Система часовых поясов

### 🔄 Универсальная логика

**Принцип работы:**
1. **Динамическое получение:** `user.timezone` из базы данных
2. **Правильная конвертация:** `pytz.localize()` → `astimezone(pytz.UTC)`
3. **Без хардкода:** Никаких фиксированных ID или таймзон

**Код:**
```python
# Получение таймзоны пользователя
user = await UserRepository.get_by_id(session, user_id)
user_timezone = user.timezone if user and user.timezone else 'UTC'

# Конвертация времени
user_tz = pytz.timezone(user_timezone)
localized_dt = user_tz.localize(remind_at_local)
remind_at_utc = localized_dt.astimezone(pytz.UTC)
```

### 🌤️ Погодная система

**Разделение данных:**
- `user.city` - для погодного API (OpenWeatherMap)
- `user.timezone` - для расчетов времени (pytz)

**Логика разрешения города:**
```python
weather_city = task.city or user.city or 'Tbilisi'
# 1. Город из задачи
# 2. Город пользователя по умолчанию  
# 3. Fallback город
```

### 🔄 FSM Flow

**Создание задачи:**
```
📅 Задачи → NLP парсинг → Календарь → Выбор времени → Сохранение
```

**Процесс:**
1. **Получение задачи:** `get_note()` - NLP обработка текста
2. **Выбор даты:** `process_simple_calendar()` - aiogram3_calendar
3. **Выбор времени:** `process_time()` - валидация HH:MM
4. **Сохранение:** `ReminderRepository.create()` + планировщик APScheduler

## ⏰ Планировщик (APScheduler)

### 🔄 Job Store

**Хранение:** SQLAlchemyJobStore (постоянное в SQLite)
**Типы задач:**
- **date:** разовые напоминания
- **interval:** периодические проверки

**Пример создания:**
```python
scheduler.add_job(
    send_scheduled_reminder,
    'date',
    run_date=remind_at_utc,
    args=[user_id, task_text, city, lang, reminder_id],
    id=f"reminder_{reminder_id}",
    misfire_grace_time=3600
)
```

## 🛡️ Безопасность и ошибки

### 🔄 Обработка ошибок

**NLP ошибки:**
- Rate limiting (429)
- API недоступность
- Невалидный JSON ответ

**Временные ошибки:**
- Неверный формат времени (HH:MM)
- Пустая дата из FSM
- Неверная таймзона

**База данных:**
- Connection errors
- Migration errors
- Constraint violations

### 📝 Логирование

**Уровни:**
- **INFO:** Основные действия пользователя
- **DEBUG:** Техническая отладка
- **ERROR:** Критические ошибки
- **WARNING:** Предупреждения

**Категории:**
- **bot_logger:** Действия пользователя
- **api_logger:** API запросы
- **scheduler_logger:** Задачи планировщика
